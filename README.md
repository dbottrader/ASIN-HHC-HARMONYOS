# ASIN-HHC-HARMONYOS

HarmonyOS-facing prototype hub for the ASIN-HHC / CP8 ecosystem.

## Current implementation

The repository presently contains a FastAPI service and browser templates for:

- a project dashboard;
- a CP8 workflow view;
- health and deployment-status endpoints;
- a glyph-coherence API surface.

The current service identifies itself as version `0.3.0`. The coherence endpoint in `heartbeat_status.py` returns a fixed placeholder score and is **not** evidence of an implemented mathematical coherence engine.
